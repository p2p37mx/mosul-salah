# مواعيد الصلاة — الموصل 🕌

- أوقات الصلاة محسوبة فلكياً للموصل (رابطة العالم الإسلامي / أم القرى / المصرية، عصر شافعي أو حنفي) + تعديل كل صلاة بالدقائق.
- عداد تنازلي للصلاة الجاية، وعداد الساعة يصير تلقائي أو يدوي (تضبط الساعة بنفسك).
- تقويم هجري وميلادي (أم القرى) مع تصحيح الهجري ±2 يوم.
- صوت الأذان: ملف صوت أو فيديو (الفيديو يشتغل صوته بس).
- صورة ثابتة أو متحركة GIF تطلع على واجهة الجوال وقت الأذان ويا عبارة «حان الآن موعد أذان …».
- أذكار الصباح والمساء وبعد الصلاة ويا عداد.

البناء تلقائي على GitHub Actions، والـ APK يطلع بـ **Releases**.
يحتاج Secrets: `SIGNING_KEY` و `SIGNING_PASSWORD` (نفس مفتاح تطبيقاتك الثانية).
